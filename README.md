# Travel Agent

Совместный планировщик путешествий: варианты дороги, жильё, события, места, бюджет и обсуждение в одной поездке.

## Сейчас реализовано

- Next.js + TypeScript;
- адаптивная структура приложения и пять вкладок поездки;
- демо-поездки и карточки объектов;
- статусы «Вишлист», «Согласовано», «Забронировано», «Нужно перепроверить»;
- локальное переключение статусов и расчёт бюджета;
- сценарий-заглушка создания поездки;
- карта, чат и источники как UI-заглушки;
- `.env.example` для будущих серверных интеграций.

## Серверный фундамент

- `supabase/migrations/202609060001_initial_schema.sql` описывает профили, поездки, участников, приглашения, план, бюджет и чат;
- в миграции включён Row Level Security;
- владелец, администратор и участник имеют разные права;
- `lib/supabase/server.ts` и `lib/supabase/browser.ts` подготовлены для подключения Supabase.
- `/api/health` показывает, настроено ли окружение Supabase;
- `/api/trips` поддерживает список поездок и создание поездки после авторизации и заполнения профиля;
- `/api/trips/[tripId]` обновляет поездку и при изменении маршрута или дат переводит связанные объекты в `recheck`.
- `/api/profile` загружает и сохраняет обязательное ФИО текущего пользователя;
- `proxy.ts` обновляет Supabase-сессию для серверных запросов.
- `/api/trips/[tripId]/plan-items` читает и добавляет варианты в план поездки;
- `/api/trips/[tripId]/plan-items/[itemId]` обновляет статус или данные варианта.
- `/api/search` использует server-only провайдеры: при наличии `TRAVELPAYOUTS_API_TOKEN` выполняет реальный запрос Aviasales Data API для билетов;
- при отсутствии ключа реальный поиск возвращает понятный статус `provider_not_configured`, а демо-данные включаются только через `SEARCH_USE_DEMO=true`;
- для других категорий добавляются отдельные провайдеры без изменения общего формата карточек.

Миграция применена к проекту Supabase через SQL Editor. Для синхронизации с Supabase CLI потребуется выполнить `supabase migration repair` после авторизации CLI.

Демо-данные намеренно не выдаются за живые: Telegram, база данных, карта и авиапровайдер подключаются отдельными задачами через серверную часть.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.
